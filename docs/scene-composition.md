# 组合场景与 GPU 场景表

## 一帧的几何和光照

组合器读取场景组件，为森林注册风系统，为流水注册播放系统，为银狼注册 Motion Matching。Cluster LOD 用缓存的几何分组取走簇实例，效果模块接管剩余实例中的程序化水面，普通网格和 GPU 蒙皮使用普通 mesh shader 绘制。效果资产可显式选择普通几何路径，避免水面重建前的原始网格进入簇绘制。普通几何与水面先于本帧 Hi-Z 构建写入深度。主剔除与延迟簇重测共享可见性目标。[组合入口](../src/experiments/composition.rs) · [几何分组](../src/render/scene/routes.rs)

`confluence` 从森林原型取一片树林，沿用台阶水面模拟和银狼动作库。示范角色使用 Toon 材质接收环境光和 ReSTIR 直接光。水面、植被和台阶使用各自的着色器。所有表面使用同一套可见性 ID 和运动向量约定。银狼使用前后骨骼姿态，水使用相同水团在前一时刻的位置，植物使用前后风姿。启用时域着色时，共享运动结果供 ReSTIR 重投影、SVGF 和 TAA 读取。新模块可从几何绘制、光照贡献、材质着色或覆盖层接入。独立的硬件光追预览和纹理压缩实验仍保留自己的入口。[运动重建](../src/render/motion.rs) · [光照贡献](../src/experiments/light_stack.rs)

`feature water off` 隐藏水带并停止积分，保留石阶。`feature forest off` 隐藏树草并停止风系统。`feature actor off` 隐藏角色并暂停动作匹配。`feature ibl off` 和 `feature restir off` 分别去掉环境光和采样直接光。开关保留相机及 ECS 中的模拟状态，重新组装技术和任务调度，时域历史从切换后的帧重新建立。当前 ReSTIR 查询刚体、GPU 蒙皮、流水及风动树草代理。此实验把水面当作双面不透明遮挡物，远近树木使用相同的射线代理，保持相机移动时的投影连续。可用固定光源检查模式对照软件与硬件结果。[几何与射线输入](../src/render/rays.rs)

## 实验如何发布快照和覆盖层

银狼模块声明一个 `VisibilityOverlay` 注册项，把播放器组件、轨迹提取函数和绘制函数放在一起。提取发生在主线程。卡通路径的可见性着色结束后，在图像描边之前，覆盖层读取可见性 ID，在已着色的 BGRA 缓冲中写入轨迹。只有快照中有对应产物，渲染线程才调用该注册项。`confluence` 使用自身的组合着色路径。关闭角色时，播放器状态仍可保存，提取函数会跳过轨迹计算。重新打开角色后恢复提取。[覆盖层注册点](../src/experiments/mod.rs) · [银狼轨迹](../src/experiments/motion/silver/trajectory_view.rs) · [卡通绘制阶段](../src/experiments/cartoon/renderer.rs)

添加场景级设置可使用 `SnapshotComponent::setting`。如果渲染器需要运行态数据，可指定提取函数，在上下文中读取组件、相关设置和世界变换，返回可跨线程共享的值。多个实体持有同一组件时按 ID 选择首个拥有者。提取器负责记录依赖、处理重新绑定和保留旧快照。[快照组件接口和回归](../src/render/scene/components.rs) · [提取流程](runtime-and-scene.md)

## 变形几何的射线对照

可见性、软件 BVH 和 Vulkan BLAS 读取同一份蒙皮网格或流水表面的 GPU 顶点。软件构建使用实例变换生成世界空间三角形并自底向上求节点边界。Vulkan 直接读取网格顶点，转换绘制索引格式，用 TLAS 放置实例。风动原型生成独立于摄像机的简化几何，在 GPU 上用相同风骨骼驱动。常规森林渲染只在有射线消费者时才发布这些代理。

- 固定光源的组合场景输出 800 × 500，软硬两条路径的可见性分类有 25 个像素不同。 [硬件遮挡](../captures/confluence-ray-hardware.png) · [软件遮挡](../captures/confluence-ray-software.png) · [射线命中法线](../captures/confluence-ray-normals.png)
- 固定银狼、石台、相机和光源，只将右臂关节旋转 1.13 弧度。480 × 360 的遮挡图变化 1,736 个像素。改变姿态后，原生路径报告 7 次加速结构更新，0 次重建。两种姿态的软件与硬件结果各差 25 个像素。 [右臂投影对照](../captures/silver-arm-shadow-comparison.png) · [复测程序](../examples/posed_ray_comparison.rs)
- 单独运行流水场景，将模拟时间设为 0 秒和 1.32 秒。相同机位下，硬件遮挡图变化 1,413 个像素，两帧的软硬结果分别差 21 和 18 个像素。集成测试还平移水面，核对送给射线后端的重建顶点资源和模型变换。 [流水回归测试](../src/experiments/effects/tests.rs)
- 只保留镜头外的一棵树和地面，固定点光源与相机。144 × 120 的画面里，风动时间从 0 秒推进到 1.7 秒后，遮挡图改变 1,121 个像素，两帧和移除树后的量化主射线深度图逐像素一致。 [镜头外投影测试](../src/experiments/composition.rs)

## 从 ECS 到 Vulkan

- 提取器为存活实例、材质分配稳定槽号。普通变换和材质编辑保留槽号与分组。增删实例时，存活对象继续使用旧槽号，新增对象可复用空槽。旧快照保留自己的映射。
- 实例列表和模型数据按 64 行分页。修改树干和树冠只替换涉及的页。相机变化不改模型表。一个模型槽占 80 B，含变换、剔除尺度、变换版本和标志；共享材质槽占 64 B，含颜色、参数、纹理索引和着色路由。普通材质和簇材质共用同一张表，特殊表面可声明覆盖参数。[提取器](../src/render/scene/incremental.rs) · [场景表](../src/render/tables.rs)
- 每个 Vulkan 帧槽持有最后一次上传的页版本，只在本槽 GPU 时间线退役后写入。先比较页身份，再比较变化页中的行。冷启动或尺寸变化可完整补表。渲染线程的时域序列按实际接收的快照确定前一帧。若 B 只提取、未绘制，C 会补齐自 A 起的净变化，并根据 A 和 C 重建运动。布局改变的过渡帧可使用完整组装路径，逐对象匹配历史。[页差分](../src/rdg/rows.rs) · [时域序列](../src/render/post.rs)
- GPU 按槽号解引用，生成供剔除、可见性着色和运动解析使用的本帧数据。CPU 无需逐个重打包森林实例。GPU 仍会展开本帧的簇记录，按视锥、LOD 和 Hi-Z 筛选。普通几何仍按 draw 生成命令，GPU 蒙皮仍接收当前需要的骨骼调色板。[簇数据生成](../shaders/cluster_tables.comp) · [普通表面生成](../shaders/ordinary_slots.comp)

## 复测

~~~powershell
cargo run --locked --release -- --experiment confluence --command "post taa"
cargo run --locked --release --example forest_scene_updates -- captures/forest-scene-updates.csv
~~~

森林含 2,665 棵树、12,580 丛草和地面，共 17,911 个渲染实例。两条路径使用相同的 ECS 增量提取器、相同的 CPU→渲染→RHI 管线、近景相机和 800 × 500 输出，关闭风和后处理，固定模拟时钟。分别连续改变相机偏航、一棵树的位置、733 个实例共用的树皮基色。每组先预热 8 帧，随后保留 64 帧，每帧比较完整路径与增量路径的 BGRA 输出。测量运行于 RTX 5070，Release 构建。基准为离屏读回，GPU 时间为设备时间戳跨度，构图和提取为 CPU 墙钟时间。[逐帧 CSV](../captures/forest-scene-updates.csv) · [基准源码](../examples/forest_scene_updates.rs)
