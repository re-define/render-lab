# 场景光源实例

光源使用实体的变换和父子层级，以可选的类型化 `Light` 组件描述类型、线性颜色、强度、作用半径和启用状态。灯可以独立存在，也可以与灯罩的网格实例挂在同一个实体上。光照参数随场景 JSON 保存，日光的本地照射方向是 −Z。

`SceneExtractor` 将启用的灯转换成只读 GPU 表。点光源使用世界平移，平行光使用归一化的世界照射方向。灯表按实体 ID 保持稳定顺序，数据相同的帧复用同一份常驻输入。光源和几何缓存分别判断变更。

方向光的 `sky_fraction` 取 0 到 1，默认 0。该比例的辐照度作为半球天空补光，其余能量按方向和太阳角半径计算。提取时合计已启用灯的天空能量。ReSTIR 在每个接收点按天空可见度加入一次，树冠使用烘焙值，普通表面使用世界法线。调节或关闭补光实体同时影响两部分。该近似没有逐像素追踪整个天空的遮挡。[光源打包](../src/render/lights.rs) · [直接光求值](../shaders/restir_shadow_eval.glsl)

普通 PBR、基础 Toon 和植被的场景光照变体按表计算直射光。ReSTIR 可对同一张表做采样与阴影查询，原来的程序化灯库仍可用来对照海量光源。ReSTIR 的历史跟随实际灯表变化重置，以保证历史中的灯索引和亮度与这一帧一致。

| 控制台指令 | 含义 |
| --- | --- |
| `light list` | 查看光源 ID、类型、启用状态、强度及平行光角半径 |
| `light point X Y Z I RANGE [R G B]` | 在指定位置创建点光源，半径以场景世界单位计 |
| `light sun DX DY DZ I [R G B]` | 创建沿该方向照射的平行光 |
| `light angular-radius ID DEGREES` | 设置平行光的角半径。ReSTIR 和 GI 命中光照在太阳圆盘内查询遮挡，0° 产生硬阴影。旧场景缺省为 0° |
| `light move ID X Y Z`、`light aim ID DX DY DZ` | 编辑局部位置，或编辑平行光的局部方向 |
| `light power ID I`、`light color ID R G B`、`light enable ID on/off` | 调整强度、线性颜色和启用状态 |
| `restir source auto/scene/bank` | 自动选择；始终采样场景实例；始终采样程序灯库 |

场景在禁用所有实体光源时保留空灯表。场景从未声明光源时，内置着色器沿用自己的默认光照，ReSTIR 的自动模式使用程序灯库。常规材质每个像素遍历活跃灯，适合少量灯光。海量灯可用 ReSTIR 的采样路径验证。
