# Modern Hall 地砖的高斯剪枝与量化

894 × 894 地砖原来有 6,554 条高斯。以原训练资产为基线，把允许的全纹理 RGB PSNR 损失设为 0.10 dB，12 档数量中满足预算的最小一档是 **3,277 条**。实际 Vulkan 着色器逐一解码 799,236 个纹素、输出 RGB8 后，原资产为 **30.6435 dB**，剪枝和量化后为 **30.6005 dB**。在 800 × 500 的场景截图上，85,766 个地砖像素的着色后 PSNR 从 31.797 降到 31.763 dB。局部图可见，原高斯拟合已平滑石材细噪声，减到 1,638 条后接缝附近的斑纹进一步消失。[变化曲线与相同位置的纹理裁剪](../captures/gaussian-pruning.png)

## 数量与重拟合

把每个高斯在各纹素的权重记为矩阵 A 的一列。对当前拟合按该列的平方和乘以 RGB 系数的平方和排序，从低到高逐档删除。在保留下来的列上，用 PyTorch 共轭梯度求三通道最小二乘，使整张源图的平方误差最小，并以 0.1 的系数惩罚颜色偏离原训练值。各档固定中心、形状与原 CUDA 覆盖边界，最终再对保留的系数做量化。这是对现有拟合的剪枝实验。[完整脚本](../tools/gaussian_ablation.py)

## 存储精度与形状

固定原来的 6,554 条高斯和颜色，只改表示方法。原有 8 个 FP32 参数直接转为 FP16，得 30.619 dB。改为相对覆盖矩形左上角的 FP16 中心、FP16 逆协方差对角项的平方根，以及有符号 8 位相关系数，几何量化后仍有 **30.648 dB**。在此基础上逐通道量化带正负号的 RGB 系数，8 位为 **30.633 dB**，6 位为 **30.438 dB**，4 位为 **27.559 dB**。6 位和 4 位为离线精度对照。运行时采用 8 位颜色与 FP32 累加。

若直接抹去协方差交叉项，轴对齐高斯为 28.530 dB，重新拟合颜色后为 29.345 dB。若换为保面积的圆形高斯，分别为 28.710 和 29.308 dB。因此这一资产保留方向性，相关系数占 1 B。最终每条记录共 **16 B**，其中中心 4 B、两个对角因子 4 B、相关系数 1 B、RGB 3 B、四个覆盖边界 4 B；原记录为 40 B。

## 索引、显存与 GPU 耗时

紧凑 tile 以量化后的椭圆重新分箱；每个列表把连续的高斯 ID 写成“起点 + 长度”。3,277 条时，16 位可容纳 12 位起点和 4 位段长编码。目录按总段数选择 16 或 32 位。紧凑 BVH 沿用同一树的划分和叶序，每节点用 4 B 存四个 16 纹素 tile 的边界，另用 4 B 存跳转位置或叶子起点及数量。GPU 仍然可以直接随机采样。8 位边界支持每轴最多 256 个覆盖 tile，即 4,096 纹素。更大的旧资产仍可选择常规 tile 或 BVH。[构建与打包](../src/experiments/gaussian/compact.rs) · [生产解码器](../shaders/materials/gaussian.glsl)

RTX 5070，release，MAILBOX，855 × 551，16 个工作线程，固定机位，每帧 103,095 个地砖像素。九种配置先正序后反序，各预热 60 帧、采样 180 帧。耗时是两轮地砖材质 pass 的 GPU 时间戳中位数。

两种 3,277 条的紧凑布局均含 52,432 B 记录和 48 B 头。tile 另含 1,572 B 目录（含对齐）和 7,283 个 16 位 ID 段，共 16,140 B 索引；BVH 另含 1,145 × 8 B，即 9,160 B 节点。相对同类旧索引和旧模型，地砖总载荷分别省 78.96% 和 79.40%。完整 atlas 还含原始木纹、壁纸与默认白纹素，位于本地显存堆。随附 G2T 是可供各模式加载的 176,680 B 交换文件；切换时在 CPU 上派生并上传所选布局。

两个紧凑解码器对全部纹素的 GPU RGB8 输出只有 10 个纹素不同，最大通道差为 1 个色阶；在固定场景机位截图上逐像素相同。[全图 GPU 对照测试](../src/experiments/gaussian.rs)

## 复测

在 `render_lab` 目录运行。使用 `compact-bvh` 可切换到更小的 BVH。原示例默认保留 6,554 条高斯与常规 tile 作为对照。

```powershell
cargo run --release --locked -- --experiment gaussian --command "gaussian load assets/gaussian/FloorTiles-pruned.g2t" --command "gaussian compact-tile" --command "gaussian stats" --benchmark 180
python tools/gaussian_ablation.py assets/scenes/modern-hall/modern_hall_core.gltf assets/gaussian/FloorTiles.ply target/gaussian-ablation --figure captures/gaussian-pruning.png
```

脚本使用 NumPy、SciPy、PyTorch、Pillow、plyfile，绘图时另需 Matplotlib。输出包括全部档位的 `sweep.json`、选中档位的 PLY 和 G2T，以及独立解码的地砖 PNG。
