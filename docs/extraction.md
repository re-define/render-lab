# 场景提取与 GPU 数据

场景提取发生在主线程向渲染线程提交快照时。`SceneExtractor::snapshot` 把世界里用于渲染的数据整理成只读的 `RenderScene`，再关联相机、尺寸和材质程序组成 `Snapshot`。因此两台相机可以消费同一版网格、实例、骨骼和光源，各自维护可见性与时域历史。[提取入口](../src/render/scene.rs) · [帧流水线](architecture.md)

## 从一次写入到下一份快照

| 世界发生的变化 | 提取器怎样处理 |
| --- | --- |
| 只移动相机 | 数据来自新的相机参数。实体变化日志为空时复用已提取的场景数据。 |
| 移动实体或父节点 | 加载这一批最终局部变换，合并受影响子树，按父子顺序更新世界矩阵。实例、关节和灯通过变换行记录的反向引用定位。 |
| 修改材质、纹理或灯 | 用稳定 ID 更新对应资源记录。实例继续引用同一资产 ID。灯同时响应自身参数与父级变换的变化。 |
| 更换刚体的局部界或阴影网格 | 替换共享资产只更新资产表及几何版本。将一个实例绑定到另一资产时，只改该实例所在页。 |
| 增删没有额外实验组件的普通网格叶节点或灯叶节点 | 记录实体 ID，更新变换行、光源表和受影响的绘制槽。删除绘制表中部的实例时，还须调整后续实例和蒙皮订阅者的索引。[实现](../src/render/scene/leaf_edits.rs) |
| 改变复杂层级，增删拥有实验组件、共享资产、骨架或簇几何的实体，或丢失日志 | 从当前世界重建拓扑与依赖。可以复用仍匹配的资产和实例。提取失败时旧快照继续有效，下一次调用从世界重新核对。 |

每个提取器有自己的变化游标。一个读者取走变化后，其他读者仍可追上；已跨过日志保留范围的读者走全量重建。局部编辑、结构编辑、姿态块和实验设置的依赖分别记录。实例按每页 64 项共享，改变个别实例时只复制涉及的页；调用连续切片接口的读者会按需展开。上一帧仍然引用的资产和矩阵通过写时复制保存。[世界变化日志](../src/scene/changes.rs) · [增量提取](../src/render/scene/incremental.rs) · [实例页](../src/render/scene/pages.rs)

## 角色与调色板

动画系统按角色发布局部姿态和脏关节集合。多个子步都写过同一关节时，提取器采用最终版本的矩阵。直接编辑实体与姿态发布重叠时，以世界里的最终局部变换为准。骨骼层级按深度优先顺序展开，每棵子树对应一段连续行。父骨移动会改变许多子骨的世界变换，因此读取的局部矩阵数和需要检查的关节槽数可以相差很大。[姿态记录](../src/scene/changes.rs) · [拓扑与矩阵](../src/render/scene/transforms.rs)

提取器从第一个关节向上找显式声明运动策略的角色根，并检查其余关节是否归属同一根。绑定成功后，关节从根以下的局部矩阵按父子顺序相乘，再乘逆绑定矩阵。同一皮肤的各部件共享结果。根平移、旋转或缩放只更新根矩阵，甚至零缩放也无需求逆。手腕局部编辑只沿腕部子树更新关节。跨独立运动根的皮肤，以及普通 glTF 中没有声明角色根的皮肤，沿用关节世界矩阵乘逆绑定矩阵。都可用全量提取逐矩阵核对。[角色空间绑定](../src/render/scene/pose_space.rs) · [增量更新](../src/render/scene/incremental.rs)

纯骨架内部只维护局部矩阵和版本。灯、绘制实例、其他世界空间皮肤、角色根所需的祖先仍然更新世界矩阵。快照扩展临时查询内部骨骼或挂载普通叶子时，沿局部链求出该处的世界矩阵。GPU 蒙皮对带权顶点使用当前显示的根矩阵与关节调色板，对零权顶点使用网格部件的模型矩阵。历史顶点从上一张已渲染快照读取同样的两项，射线几何读取当前世界空间顶点流。每个 Vulkan 在途槽用自己上次退役的姿态表核对矩阵，只写内容发生变化的记录，首次使用或扩容需要初始化。构图仍会整理当前帧的矩阵，因此实际上传字节与 CPU 构图时间分开测量。[蒙皮与射线输入](../src/render/geometry.rs) · [GPU 批处理](../src/render/geometry/skin.rs) · [姿态表上传](../src/rdg/rows.rs)


### 相同编辑下的两种姿态表示

使用 500 名银狼、3,000 个蒙皮实例，交替提取同一序列中的两个世界。参考世界移除显式角色根声明，走世界空间关节路径，另一个世界保留声明。每种编辑预热 4 帧后取 48 帧，末帧给所有关节重新乘根矩阵，逐项与参考核对。以下是 Ryzen 7 9700X 的 release CPU 结果，仅统计构建快照。手腕的 8,000 项等于 500 名角色各 16 个相关关节。[基准实现](../src/experiments/motion/silver/contact/crowd_profile.rs)

| 每名角色的编辑 | 世界空间关节槽 | 角色空间关节槽 | 世界空间提取 P50 / P95 | 角色空间提取 P50 / P95 |
| --- | ---: | ---: | ---: | ---: |
| 只移动根 | 159,500 | 0 | 6.66 / 8.01 ms | 2.06 / 2.95 ms |
| 只移动右腕 | 8,000 | 8,000 | 2.80 / 3.16 ms | 2.76 / 3.16 ms |
| 修改全部 21 个动作关节 | 159,500 | 159,000 | 10.94 / 11.71 ms | 8.97 / 10.21 ms |

```powershell
$env:RENDER_LAB_NPCS = '500'
cargo test --release --locked --lib silver_crowd_palette_paths -- --ignored --nocapture
cargo test --release --locked --lib batched_gpu_skin_matches -- --ignored --nocapture
```

RTX 5070 的 Vulkan 回归直接读回两名角色的当前顶点和历史顶点。四次连续移动根，带权与零权顶点均与预期相同。首次上传四个矩阵共 256 B，两个帧槽预热后只动根的帧上传 0 B 姿态。银狼抬起手臂后有 7 次硬件 AS 更新，变化的阴影像素为 1,736，其中主视深度未变的接收面像素为 1,263。同一姿势的软件和硬件阴影分别有 25 个差异像素。300 名银狼在 1080p 的批量绘制与参考绘制逐像素一致，覆盖 13,780 个可见性与深度像素和 11,536 个运动向量与历史对应像素。[蒙皮读回](../src/render/geometry/skin.rs) · [软硬光追对照](../examples/posed_ray_comparison.rs) · [可见性与运动向量对照](../src/experiments/motion/silver/contact/crowd_draw_test.rs)

## 资产和实验如何进入快照

- 可共享的网格、材质、纹理、局部界与阴影代理有各自的资产 ID。几何路由为普通网格与簇网格保存实例槽，模型和材质获得可复用的 GPU 表槽。射线与可见性对资产的不同用法见[几何与着色](rendering.md)。
- 实验用 `SnapshotComponent` 声明设置键、关联设置及可选提取函数。对场景级键，带有该键的最小实体 ID 是提供者。通过 `SnapshotContext` 读取设置和世界变换会登记依赖，后续只重新计算受影响的派生值。[组件提取接口](../src/render/scene/components.rs)
- 纹理内容更新后，图集为发生变化的区域准备数据；容量不足时需要扩容和重新上传。帧槽仍引用旧版本时，两个版本可同时占用显存。判断更新成本应分别看 CPU 提取耗时、图集写入字节和 Vulkan 实际绑定字节。[纹理图集](../src/render/atlas.rs) · [分页数据](../src/rdg/rows.rs) · [森林树皮回归](../src/render/atlas/tests.rs)

## 验证与测量

在仓库根目录运行以下命令。第一个命令检验双读者、稀疏编辑、层级和资产重绑。第二个逐矩阵比较独立读者的增量提取和全量提取，覆盖稀疏关节、密集变化及重新绑定。第三个用固定森林依次测相机移动、单树移动、共享树皮参数变化。

```powershell
cargo test --release --locked --test ecs_changes --test geometry_assets
cargo test --release --locked --lib sparse_dense_and_rebound_pose_blocks_match_full_extraction_for_every_reader
cargo run --release --locked --example forest_extraction
```

解读记录时，`entities_visited` 数本次提取实际访问的实体，`instances_updated` 数变动的渲染实例，`pose_locals_read` 数从姿态位图读取的局部变换，`palette_joints_examined` 数实际检查的调色板槽。银狼压测将六个固定子步的模拟耗时与随后一次提取分别采样；窗口帧间隔另行测量。[森林测量程序](../examples/forest_extraction.rs) · [银狼人群基准](../src/experiments/motion/silver/contact/crowd_profile.rs) · [性能记录](performance.md)
